PROJECT TITLE

Smart Project Submission Portal

1. ABSTRACT

A modernized, distributed platform for managing academic project proposals, dynamic module workflows, and automated synopsis compilation.

2. TECHNICAL SCOPE & ARCHITECTURE

The system utilizes an asynchronous Express runtime backed by secure session layers. Dynamic DOM trees render module cards while client-side rasterizers compile structured A4 reports.

3. DYNAMIC MODULE BREAKDOWN

Mod # Module Designation Functional Scope & Engineering Details
1 Identity Authentication & Local Persistence Layer Enforces salted cryptographic password hashing via bcryptjs, manages session states, and guarantees persistence using serialized flat-file JSON storage.
2 Generative AI Prompt Orchestration Subsystem Integrates Google Gemini to evaluate problem statements, polish academic abstracts, and dynamically architect project modules via structured JSON schemas.
3 Client-Side Document Typesetting & Vector PDF Engine Implements real-time bi-directional DOM synchronization with a virtual A4 layout and renders print-ready vector PDF documentation using client-side rasterization.

4. LITERATURE SURVEY

Evaluated comparative models in client-side document rendering and JSON database persistence across low-resource academic hosting environments.
